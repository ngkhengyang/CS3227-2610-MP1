# AI-assisted development note

Hidden the redundant `Modules credited to ...` section when a specific-module
requirement is selected. Its required modules and completion progress remain
visible in the existing progress and Requirements sections, while allocation
details for count, unit-count, unrestricted-elective, and degree-total
requirements remain available.

Verified with `gradle --no-daemon test` using Java 25 and Gradle 9.7.1.
